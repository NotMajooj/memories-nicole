MEMORIES ♥ NICOLE
=================

O site inteiro está nesta pasta. Não precisa instalar nada.

TESTAR NO COMPUTADOR
- Abra o index.html no navegador (Chrome, Edge ou Firefox).
- As fontes pixel vêm do Google Fonts, então precisa de internet.

COLOCAR NO AR (escolha um)
1) Netlify Drop (o mais fácil, grátis):
   - Entre em https://app.netlify.com/drop
   - Arraste a PASTA memories-nicole inteira pra página.
   - Ele gera um link na hora. Dá pra mudar o nome do link nas configurações do site.
2) GitHub Pages (grátis):
   - Crie um repositório, suba todos os arquivos desta pasta (index.html na raiz).
   - Settings → Pages → Source: "Deploy from a branch" → branch main → / (root).
   - O link fica: https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

ESTRUTURA
- index.html ............ todo o app (HTML, CSS e JS)
